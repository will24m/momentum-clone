Download

Manual install

This build is not in the Chrome Web Store yet. Download the ZIP, unzip it, then load the extracted folder in Chrome.

  1. Download the ZIP.
  2. Unzip it.
  3. Open chrome://extensions.
  4. Turn on Developer mode.
  5. Click Load unpacked.
  6. Select the extracted dist folder.
